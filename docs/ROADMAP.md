# Roadmap

## Phase 1: Starter baseline

- Astro + MDX project shell
- Content schema for render metadata
- Five scene presets
- Scroll-triggered DOM animation bridge
- Render bus for scene updates
- Example posts

## Phase 2: Authoring improvements

- Scene parameter inspector
- Better timeline debugging overlay
- More granular material controls
- Poster generation workflow
- Real GLB demo assets

## Phase 3: Advanced rendering

- Shared persistent Canvas across article sections
- WebGPU experiment branch
- Shader graph or node-material experiments
- KTX2 and Meshopt compression pipeline
- LOD and performance profiling utilities

## Phase 4: Text-to-schema assistance

- Natural language prompts that generate `render` YAML
- Preset recommendation from post content
- Automatic camera path drafts
- Auto-generated comparison tables and parameter cards
